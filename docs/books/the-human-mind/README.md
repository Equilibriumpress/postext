# THE HUMAN MIND · Postext visual edition

Native Postext A4 composed-page adaptation of the 80-page PagedPress source. The 80 authored page fences correspond to the five opening pages, 36 two-page chapters (6 themes plus 30 books), and three closing pages. This is not yet a verified identical 80-page PDF. The original typography and CSS could not be copied directly into Postext, so editorial layouts use native Postext frames and require visual review for overflow, fidelity and Apple Books output.

The 30 original SVG diagrams and cover are shared with the complete Postext reading edition. Source: Equilibriumpress/PagedPress, commit 9ed47d315c945439feeb6bb9a3ec72a74a477a63.
