# Where does all the information go?
:::
:::frame{slot="metadata"}
The Organized Mind · Daniel J. Levitin
:::
:::frame{slot="left"}
**01 · Attention has competing demands**

A stream of competing signals can pull attention away from chosen priorities. The problem is not solved by trying to notice everything.

**02 · Task switching carries costs**

Switching between a report and alerts adds restart costs. Protect a period for one demanding task when the work and circumstances permit it.

**03 · Categorization reduces search**

A clear category or filing location reduces the time spent searching. An overly complicated system creates its own burden.

**04 · Written systems offload memory**

Writing a reminder transfers some memory demands into the environment. Its value depends on consistently reviewing the list.
:::
:::frame{slot="right"}
**05 · Environment shapes focus**

Desks, devices and notification settings continually cue action. The arrangement of a workspace affects what is easiest to do.

**06 · Decision fatigue has limits**

Repeated small choices can be tiring, but broad claims about a fixed supply of willpower are debated. Reduce avoidable decisions.

**07 · Priorities require protected time**

Put commitments in a system you will review. A growing list you never trust transfers the burden of remembering without solving it.

**08 · Information hygiene matters**

Not all information deserves immediate attention. A useful filter distinguishes urgent input from material that can be batched.
:::
:::frame{slot="applications"}
## Two things to try

**09 · Capture all unfinished tasks**

List every unfinished task in one notebook or app. Mark the next action for the top three.

**10 · Protect one focused work interval**

Mute notifications for a 25-minute work period. Record interruptions for later review.
