# How small actions become repeatable
:::
:::frame{slot="metadata"}
Atomic Habits · James Clear
:::
:::frame{slot="left"}
**01 · Identity gives a direction**

A goal defines an outcome. A repeated action also provides evidence for the kind of person someone wants to become.

**02 · Make the cue obvious**

Put a reliable cue where the desired action happens. A visible book invites reading, but the cue cannot guarantee time or attention.

**03 · Connect it to a routine**

An existing daily event supplies a dependable starting point. An after-this-then-that plan is often more precise than an intention.

**04 · Lower the first-step cost**

Preparing tools and making a two-minute version reduces startup friction. Ease does not replace the need for later practice.
:::
:::frame{slot="right"}
**05 · Make the action attractive**

Pair a useful task with something enjoyable where appropriate. Repetition grows easier when the experience is tolerable.

**06 · Use an immediate signal**

A simple completion mark makes progress visible. The reward should reinforce the action rather than overwhelm the original purpose.

**07 · Shape the surroundings**

Change one feature of the surroundings before demanding more willpower. Check whether the change reduces effort in your actual routine.

**08 · Restart without drama**

A missed day is information about the routine. Adapt the plan and return to the smallest version rather than waiting for a perfect restart.
:::
:::frame{slot="applications"}
## Two things to try

**09 · Design a two-minute starting action**

Choose a wanted routine and write a version you can begin in two minutes. Try it today.

**10 · Change one environmental cue**

Place the useful object where the routine begins and move one distraction farther away.
