# Why thinking depends on knowledge
:::
:::frame{slot="metadata"}
Why Don't Students Like School? · Daniel T. Willingham
:::
:::frame{slot="left"}
**01 · Background knowledge aids comprehension**

Relevant background knowledge lets a reader infer relationships that remain obscure to a beginner. Comprehension is more than decoding words.

**02 · Memory supports complex reasoning**

New information competes for limited working memory. Reduce simultaneous demands without removing the underlying intellectual challenge.

**03 · Attention favors meaningful problems**

A carefully framed problem attracts attention when the learner sees a path to an answer. Confusion without a foothold discourages thought.

**04 · Practice makes basic skills automatic**

Repeated foundational practice makes some operations faster. This leaves attention for meaning rather than every basic step.
:::
:::frame{slot="right"}
**05 · Understanding needs examples**

Abstract rules are clearer when grounded in several contrasting examples. A single example is easy to copy without understanding.

**06 · Working memory has limits**

Instruction should keep the number of simultaneously new demands manageable. Simplifying a task is not the same as reducing its ambition.

**07 · Feedback supports expertise**

Feedback should identify the step or assumption that failed. More practice without that information may repeat the same mistake.

**08 · Mental effort depends on task design**

The difficulty of a task depends on what a person already knows. Adapt teaching to the learner's present knowledge, not an assumed style.
:::
:::frame{slot="applications"}
## Two things to try

**09 · Teach through contrasting examples**

Show two examples of one rule. Ask the learner what changes and what stays the same.

**10 · Practice a prerequisite first**

Identify one missing basic skill. Practice it with feedback before adding the next step.
