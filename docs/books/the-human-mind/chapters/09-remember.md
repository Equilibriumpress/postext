# Why forgetting is part of remembering
:::
:::frame{slot="metadata"}
Remember · Lisa Genova
:::
:::frame{slot="idea1"}
**01 · Attention gates memory formation**

Memory begins with attention. A name heard while planning the next sentence may never be encoded strongly enough to retrieve.
:::
:::frame{slot="idea2"}
**02 · Forgetting is a normal brain process**

A distracted introduction may leave little information to retrieve later. Give the name and the person your attention before choosing a memory trick.
:::
:::frame{slot="idea3"}
**03 · Sleep supports consolidation**

Sleep supports memory consolidation, although its effects vary across tasks. A single poor night does not define someone's capacity.
:::
:::frame{slot="idea4"}
**04 · Association aids retrieval**

A new fact is easier to retrieve when linked to a distinctive image or meaning. A random repetition has fewer retrieval paths.
:::
:::frame{slot="idea5"}
**05 · Emotion affects what is retained**

Emotion changes what stands out during an event. A vivid central detail can coexist with poor recall for surrounding information.
:::
:::frame{slot="idea6"}
**06 · Stress can obstruct recall**

Stress affects attention and retrieval in complex ways. Temporary blankness under pressure does not show what a person truly knows.
:::
:::frame{slot="idea7"}
**07 · Cues help recover details**

Forgetting can follow weak encoding, interference or a retrieval problem. One missed name alone cannot tell you which explanation applies.
:::
:::frame{slot="idea8"}
**08 · Memory is not a perfect recording**

Remembering involves reconstruction. A sincere and vivid recollection is not a perfect recording of the past.
:::
:::frame{slot="practicehead"}
## Two things to try
:::
:::frame{slot="practice1"}
**09 · Give a name your attention**

At an introduction, repeat the name and connect it to one detail. Try recalling it later.
:::
:::frame{slot="practice2"}
**10 · Set a reliable reminder**

Enter one appointment in a calendar now, including its time. Check the calendar at a set hour.
