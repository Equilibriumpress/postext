# Equilibrium Press · Postext Studio

This proof book is served directly from the \`docs/books/\` directory of the GitHub repository. The complete upstream Postext Sandbox is the reader and publisher.

The permanent source is [Equilibriumpress/postext](https://github.com/Equilibriumpress/postext). This link also serves as a first hyperlink-export specimen.

## What this edition checks

- The existing Books shelf loads an additional GitHub-hosted preset.
- Markdown chapters and an SVG illustration become print-ready pages.
- PDF, fixed-layout EPUB 3 and reflowable EPUB 3 use the same source.
- Updates to the book files do not require a new application build.

This is a technical proof, not a migrated edition of an existing PagedPress title.
