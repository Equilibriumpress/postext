# Source design

Edit DESIGN-SPEC.json, design/typography-and-layout.json, design/page-families.json or design/book.json, then run `python3 docs/books/dinas-island-premium/build_preset.py` from the repository checkout. The official preset_kit writes the generated preset and fingerprint and checks all file references. All editorial text remains in chapters, except the short resource caption attached to its illustration. Source design remains independent of the rendered static library.
