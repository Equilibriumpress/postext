# Visual Atlas

Native flow configuration adapted from `apps/web/public/presets/pintura-espanola/preset.json`. Book-specific cover and opener designs, pictures and icons are omitted. Open font families Archivo and Newsreader replace source-specific faces. Font blobs originate from the upstream Deep Sky preset. See the upstream font credits and OFL license terms. These are layout starters, not facsimiles or approved books.

Copy the folder to a new book ID, replace the sample Markdown and add the actual illustrations. Follow the postext-port skill and the production protocol before approval.
