# Studio templates

See [upstream-layout-catalog.md](upstream-layout-catalog.md) for all eleven source examples and the four editable starter books registered under docs/books/template-*.

To make a new book, copy one starter folder, assign a unique ID, supply the original chapter Markdown and resources, and add a single catalog entry. For fixed source layouts, use the native composed-page references instead of forcing an entire book into a flowing magazine template. Follow the production protocol.
