# Map preparation — MAP-11–17
Use [the same-origin preparation page](https://equilibriumpress.github.io/postext/map-preparation.html), not normal book opening, for OpenFreeMap queries. First prepare Water structure, inspect its preview and report. Figure-ground and network buttons become available after the first prepared image exists. Each style is explicitly prepared, sequentially, with one worker per attempt. Six tiles, 768 KiB per tile, 3 MiB per attempt, 500 KiB source SVG. On budget failure retry at zoom 13 within the same 25-second network/decoder deadline. Exact tile ID, bytes and decoder counts/errors are shown; copy the report for debugging. No extra server or Actions.
CacheStorage on the Studio origin holds the original vector SVG and a separate simple SVG containing one embedded PNG 1800×1185. This is deliberately a bounded map-specific bitmap representation: it targets the native PDF SVG image XObject path without text font fallback. Place labels remain native. Actual PDF dimensions must be checked, not assumed. The original vector remains available in the preparation preview and local cache. Other resources and the layout/PDF engine are unchanged. The book uses the cached prepared image, or a clearly marked local reserve with the error reason; normal opening does not request map tiles. Native preset fingerprint includes the cache revision. Reopen the book in the same browser/profile. Clearing site storage removes prepared maps; do not clear it just to refresh a book. CLI still reads the original local SVG reserve. Real network, native renderer and all exports remain unverified.
