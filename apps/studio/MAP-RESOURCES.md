# Bounded browser vector maps — MAP-01–10

Replaces the previous PDOK BGT GeoJSON adapter after a reported browser crash. Reuses PagedPress's `src/lib/cartography/vectorPrint.worker.js` at commit `9ed47d315c945439feeb6bb9a3ec72a74a477a63`, adapted for integer print coordinates, subpixel simplification, viewport rejection and smaller budgets. No external JavaScript CDN or engine changes. Tiles come from OpenFreeMap, attribution © OpenStreetMap contributors. Roads are centrelines, not BGT road polygons.

Descriptor v2: `{version:2,source:"openfreemap",style:"water-first",enabled:true,bbox:[west,south,east,north],points:[[lon,lat]]}`. Existing local marked SVG fallback remains mandatory. Only water-first enabled in Amsterdam. Other styles deliberately paused pending actual Safari test. Six tiles at zoom 13–14, 768 KiB per tile, 3 MiB total, 14-second deadline, 500 KiB SVG limit. Single tile decoded per worker message, transferred bytes, worker terminated on success/failure. No decoded geography cache. When buildings exceed their secondary budget the water map says so; figure-ground must retain buildings. Failure returns marked reserve. Source data is generalized for print. Console shows timing and bytes.

Book opening still waits for native resource loading. The one-map gate is intentional. Real tile/CORS test, native rendering, actual timings, PDF and both EPUBs remain unverified. Do not activate other styles until the active map passes. CLI uses marked local reserve. No manual Actions.
