# Automatic live map resources v4

The user browser log confirms OpenFreeMap and the PagedPress decoder work quickly. The v3 caps caused zoom downgrade and building omission. v4 renders the three Amsterdam styles from one shared zoom14 tile batch automatically as the normal native remote preset loads. There is no mandatory map preparation step. Existing diagnostic page is optional. Browser CacheStorage holds prepared images and source vectors, but inability to cache does not block a freshly generated map. New version cache namespace prevents use of v3 maps. One tile at a time, 2 MiB per tile, six tiles, 12 MiB total, 400k vertices per tile, 6 MiB aggregate path markup, 25-second network/decoder budget. No automatic downgrade or silent loss of the building layer. Three sequential 1800×1185 canvases avoid giant SVG decoding; the native SVG wrapper contains the bounded PNG. Native Markdown labels preserved. Maps are not yet true progressive replacements of already displayed pages: the unchanged remote preset loader awaits its resources.
